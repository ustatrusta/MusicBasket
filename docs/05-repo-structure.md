## 7. Tooling Notes

- pnpm workspaces: `apps/*`, `packages/*`.
- Turborepo pipeline: `lint → typecheck → test → build` with caching; `dev` runs mobile+backend together.
- Node ≥ 20, pnpm ≥ 9, Expo SDK (current stable), React Native 0.7x, NestJS 10/11.
- All config validated on CI; secrets never committed (`.env` files git-ignored; `.env.example` committed).
